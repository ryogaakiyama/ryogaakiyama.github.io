プライバシーポリシー

Securiy（YouTube チャンネルとこの紹介サイト）での、個人情報の扱いについて

1. 基本方針

Securiy（以下「当チャンネル」）は、YouTube チャンネル「Securiy」と、その紹介サイト（https://ryogaakiyama.github.io/ 、以下「本サイト」）を運営しています。当チャンネルは、利用者の個人情報を大切に扱い、必要な範囲を超えて集めたり使ったりしません。

2. 本サイトで集める情報

本サイトには、お問い合わせフォームや会員登録、アクセス解析（Google アナリティクス等）、広告はありません。当チャンネルが本サイトを通じて、氏名やメールアドレスなどの個人情報を直接集めることはありません。

ただし、本サイトを表示するために、次の外部サービスを利用しています。これらのサービスには、閲覧時に IP アドレスやブラウザの情報などが送られます。

GitHub Pages（GitHub, Inc.）本サイトの公開に利用しています。セキュリティや運用のため、アクセス記録（IP アドレス等）が GitHub によって記録されることがあります。
GitHub のプライバシーに関する声明
Google Fonts（Google LLC）文字の表示（フォント）に利用しています。フォントの読み込み時に、IP アドレス等が Google に送られます。
Google プライバシーポリシー
YouTube（Google LLC）動画の埋め込みに利用しています。プライバシー強化モード（youtube-nocookie.com）を使っていますが、動画を再生すると YouTube が Cookie 等を使う場合があります。
Google プライバシーポリシー

3. YouTube チャンネルでの情報

当チャンネルの動画の視聴、コメント、チャンネル登録などは YouTube 上で行われ、その情報は Google が管理します。取り扱いは Google のプライバシーポリシーに従います。

当チャンネルは、YouTube Studio で、YouTube が提供する集計済みの統計（再生回数、視聴者の年齢層や地域の割合など）を、動画の改善のために見ることがあります。これらは個人を特定できない形で提供されるものです。

コメントに個人情報（氏名、連絡先など）を書かないようお願いします。個人情報や、他人を傷つける内容を含むコメントは、削除することがあります。

4. 第三者への提供

当チャンネルは、法令に基づく場合を除き、利用者の個人情報を第三者に提供しません。

5. 動画の制作について

動画のナレーションには AI 音声（Google の Gemini TTS）を使用しています。動画に、視聴者の個人情報を使うことはありません。実在の企業や団体を扱う場合は、公開情報に基づいて紹介し、出典を概要欄に記載します。

6. 免責事項

本サイトと当チャンネルの内容は、公開時点の公開情報をもとに作成しています。正確さには注意していますが、内容が古くなったり、誤りを含んだりする可能性があります。本サイトや動画の情報を使って生じた損害について、当チャンネルは責任を負いかねます。対応の際は、各ベンダーや公的機関の最新情報もご確認ください。

本サイトからリンクしている外部サイトの内容については、各サイトの運営者にお問い合わせください。

7. お問い合わせ

本ポリシーに関するお問い合わせは、YouTube チャンネルの動画のコメント欄、またはチャンネルの概要に記載の連絡先からお願いします。

8. 改定

本ポリシーは、必要に応じて改定することがあります。改定した場合は、本ページでお知らせします。
