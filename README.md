# ryogaakiyama.github.io

Securiy（セキュリティ・AI・データを1〜3分で解説する YouTube チャンネル）の紹介ページ。GitHub Pages で公開する。

- 本体: `index.html`（1ファイル。フラットカラーのみ、動画と同じ配色・ロゴ）
- プライバシーポリシー: `privacy.html`
- 編集する箇所: `index.html` 末尾の `CHANNEL_URL`（チャンネルのURL）と `VIDEOS`（公開済み動画のIDと題名）
- 公開設定: Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にする
